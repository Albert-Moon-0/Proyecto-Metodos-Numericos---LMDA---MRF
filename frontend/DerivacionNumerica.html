Derivación numérica

Derivación numérica: 2, 3 y 5 puntos

Aproxima f′(x₀) a partir de datos tabulados o de una función f(x) con nodos igualmente espaciados. Elige la fórmula (o deja que se escoja la de mayor orden), compara todas las fórmulas, mira la recta tangente y estudia cómo el paso h afecta el error.

Configuración

Datos de entrada

Se toman N nodos equiespaciados entre a y b (incluyendo ambos extremos), con h = (b − a)/(N − 1). Como se conoce f(x), la derivada exacta se calcula de forma simbólica y se muestra el error real, la extrapolación de Richardson y el análisis del paso h.
